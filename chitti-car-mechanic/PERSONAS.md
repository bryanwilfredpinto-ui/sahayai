# PERSONAS — Chitti Car Mechanic

Full validation-stage personas (pain/goal/frustration/a11y) live in
[PRODUCT_JUSTIFICATION.md](PRODUCT_JUSTIFICATION.md) Phase 3. The 9 accessibility archetypes Chitti
must serve (CEOS §3), with the design adaptation each gets via `chitti_a11y.js`:

| Code | Archetype | ~Population | Primary need | Chitti adaptation |
|---|---|---|---|---|
| BLIND | Blind / very low vision | ~5M | Non-visual | Audio + screen reader; 🔊 on every box; auto-read |
| DEAF | Deaf / HoH | ~6M | Visual-only | Captions + symbol+word status (never colour-only) + ISL |
| MUTE | Speech difficulty | ~2M | No speech | Tap + type + select; voice optional |
| ILLITERATE | Cannot read text | ~250M | No text | Emoji icons + voice in/out + plain English |
| ELDERLY | 65+ | ~150M | Large targets | ≥48px taps, slow speech, repeat |
| LOW_VISION | Low vision | ~50M | Magnification | reflow, 400% zoom, no fixed-px traps |
| COGNITIVE | Cognitive | ~20M | Simplified | one step, no flashing, reduced-motion |
| MOTOR | Limited mobility | ~15M | No mouse | keyboard/voice nav, ≥44px |
| RURAL | Low connectivity | ~900M | 3G/offline | offline-first engine; SMS reminder path (🟡) |

**Design-call persona (validation):** the **livelihood driver** (Ola/Uber/delivery/fleet — car = income)
and the **vernacular family** — the segment every English/text/dongle/technical competitor structurally excludes.
