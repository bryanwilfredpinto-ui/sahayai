## PASSIVE LEARNING & SWARM INTELLIGENCE

> "Chitti never sleeps. Even in silence, Chitti listens and learns."

### Idle Mode Behaviour:
- When not actively used, Chitti enters near-zero resource mode
- Passively listens to understand pronunciation, dialect, local patterns
- Never learns new words — only deepens understanding of existing ones
- Each language has a textbook-standard vector DB as its foundation
- Learned patterns stored in Turso — never mixed with core language base

### Swarm Intelligence:
- All 15 Chittis share dialect + pattern learnings weekly via Swarm cron
- What Chitti News learns in Tamil — Chitti Vaani also knows next week
- Collective intelligence grows without any single Chitti being overloaded
- Swarm cron runs Sunday 09:00 IST — committed, Railway verified

### LLM Independence Goal:
- Today: Gemini → Claude → DeepSeek fallback chain
- Tomorrow: Cached local responses from learned patterns
- Future: Chitti speaks its own language — no external LLM dependency
- CTO builds toward this — one Chitti at a time, starting with Vaani

### Commando Standard:
- Idle mode must use less than 5% CPU and zero API calls
- Swarm sharing must never expose one user's data to another
- Local cache must cover top 100 most common user queries per language
