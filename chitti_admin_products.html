Setup checklist
1. Set ADMIN_SECRET in Render env (any random 32-char string).
2. For persistent storage, set ADMIN_DATABASE_URL to your Supabase Postgres URL — otherwise tokens live in /tmp and vanish on restart.
3. In Google Cloud Console → OAuth client → Authorized redirect URIs, add: /api/admin/products/oauth/callback
4. Click Authorize on each product row and sign in to Google as that mailbox. The dashboard warns if you sign in as the wrong account.
5. Monthly keep-alive runs at day=1, 06:00 IST — change via ADMIN_KEEPALIVE_* env vars. Recipient: sire@gmail.com.
