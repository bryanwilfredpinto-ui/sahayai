# SWARM — 10 agents vote before any signal shows

No signal reaches the user as one indicator's raw opinion. Ten agents score in
parallel; the shown verdict is the **synthesized confluence**, gated by Trust and
phrased by Explain. This mirrors the chitti-fashion / chitti-mechanic swarm
doctrine ([SAHAYAI_MASTER.md §2a/§2f](../../SAHAYAI_MASTER.md)).

## The ten agents

| # | Agent | Judges | Can it move the verdict? |
|---|---|---|---|
| 1 | [Trend Agent](trend-agent.md) | higher-timeframe trend | **Yes — governs direction** (Founder Rule #4) |
| 2 | [Momentum Agent](momentum-agent.md) | RSI · MACD · Stochastic · Williams %R | Yes — confirms/denies |
| 3 | [Volume Agent](volume-agent.md) | participation / confirmation | Yes — can veto "confirmed" |
| 4 | [Pattern Agent](pattern-agent.md) | chart patterns / structure | Yes |
| 5 | [Roshan Agent](roshan-agent.md) ⭐ | Sire's custom composite | Yes — one weighted voter |
| 6 | [Risk Agent](risk-agent.md) | stop · RR · position size | **Yes — can BLOCK** (no stop → no signal) |
| 7 | [Confluence Agent](confluence-agent.md) | weighted voting / synthesis | **synthesizer** — produces the verdict |
| 8 | [Trust Agent](trust-agent.md) | final verification / guardrails | **Yes — can BLOCK / downgrade** |
| 9 | [Accessibility Agent](accessibility-agent.md) | blind/deaf/illiterate delivery | shapes delivery, not the verdict |
| 10 | [Chitti Explain Agent](chitti-explain-agent.md) | plain-language reasoning | phrases the verdict, never invents it |

## Voting model

```
Trend ─┐
Momentum ─┤
Volume ─┤            Confluence Agent (7)
Pattern ─┼──────────▶ weighted vote, higher-TF heaviest
Roshan ─┘                    │
                             ▼
                        Risk Agent (6) — stop/RR valid? else BLOCK
                             │
                             ▼
                        Trust Agent (8) — guardrails / SEBI / no-hallucination
                             │            else BLOCK → "no clean trade"
                             ▼
                Accessibility (9) + Explain (10) — deliver to the 4 users
```

### Weighting principles

- **Higher-timeframe agreement weighs heaviest.** A trigger-timeframe BUY against
  a higher-timeframe downtrend cannot produce a BUY — at best a cautious counter-
  trend note, usually a HOLD.
- **Confirmation agents can subtract but not manufacture.** Volume can downgrade a
  breakout to "unconfirmed"; it cannot upgrade a no-trend chart to a BUY.
- **Risk and Trust can block.** They are veto agents, not score agents — a
  beautiful setup with no clean stop is still a no-trade.
- **Disagreement caps confidence.** Wide agent disagreement → LOW confidence or HOLD.

## Honest-uncertainty rule

When the agents genuinely disagree, the swarm does **not** average them into a
mushy "weak BUY." It returns **HOLD** with the disagreement explained. Founder
Rule #5 — trust over excitement.
