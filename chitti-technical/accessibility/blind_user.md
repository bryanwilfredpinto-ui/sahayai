# ACCESSIBILITY — Blind trader (P5)

> A blind trader must receive the **same institutional-grade analysis** as a
> sighted one — by voice, in their language. The chart is narrated; the signal is
> spoken; nothing is carried by colour.

## Core experience: Audio Trade Summary
Every signal can be spoken in a fixed, learnable order:
1. **Instrument + trade type** — "RELIANCE, swing."
2. **Verdict + confidence** — "Medium-confidence buy."
3. **Trend** (higher TF first) — "Weekly up, daily turned up with volume."
4. **Entry** — "Buy near ₹2,860."
5. **Stop** — "Stop ₹2,820 — you're wrong below there."
6. **Targets + RR** — "Target ₹2,900, then ₹2,960. Risk ₹40 to make ₹80."
7. **Invalidation** — "Not a buy if the daily closes below ₹2,820."
8. **Disclaimer** — "Educational, not advice. Not SEBI registered."

## Requirements (all mandatory)
- Every response box reads aloud (🔊) via Voice Factory in the selected language.
- Page **auto-announces on open** for blind-profile users ([SAHAYAI_MASTER.md §5c](../../SAHAYAI_MASTER.md)).
- **"Describe this chart"** narrates structure + active indicators.
- **No visual-only errors** — every error is spoken.
- Numbers spoken clearly (₹, %, RR as "one to two").
- Slow-speech + repeat ("say that again, Chitti") available.
- The verdict is **always available as text+audio**, never only as a chart.

## Anti-patterns (defects)
- A signal conveyed only by a green/red colour. ❌
- A chart with no narration path. ❌
- An error toast with no spoken version. ❌
