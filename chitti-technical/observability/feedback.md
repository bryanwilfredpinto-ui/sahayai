# OBSERVABILITY — Feedback (per-response widget + swarm learning)

## The per-response widget (mandatory, every card)
Per [SAHAYAI_MASTER.md §7](../../SAHAYAI_MASTER.md), every response box carries the
5 elements via `feedback-widget.js` (attached to `data-chitti-response`):
- 🔊 speaker · 🤖 Chitti-explain · 👍 / 👎 · ✏️/🎙️ per-box feedback window.

👎 opens a per-box feedback popup ("What was wrong with this signal?"), voice or
type, tagged to the box ID → daily founder report.

## What feedback teaches (Swarm Intelligence, [SAHAYAI_MASTER.md §2f](../../SAHAYAI_MASTER.md))
- High-👍 explanations → reinforce phrasing patterns in `skills/*.md`.
- 👎 → follow-up → 👍 reversals → "what fixed it" pattern.
- Recurring 👎 on a specific indicator's explanation → fix that explainer.

## Hard limits on learning (HIGH-risk product)
- Chitti Technical touches users' money → treat skill changes like a HIGH-risk
  Chitti: **≥100 confirmations + Sire review before any swarm patch lands.**
- **The Roshan formula is NOT learnable** — it changes only on Sire's sign-off
  ([../indicators/ROSHAN.md](../indicators/ROSHAN.md)).
- **Locked decisions never learnable** (SEBI disclaimer, no-guarantee, stop-mandatory,
  DeepSeek-only, Vaani-sole-interface).
- The swarm may tune *explanation quality* freely; it may **never** loosen a
  guardrail or invent a new signal type without Sire.

## Privacy
- Feedback is anonymised before aggregation; the user owns it; "Chitti forget"
  removes it (tombstone preserved).
