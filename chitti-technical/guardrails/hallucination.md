# Guardrail — Hallucination / No-fabrication (L8)

**Rule:** Chitti Technical never invents numbers, signals, or certainty.

- **Deterministic engine.** Signals, indicators, pivots, risk, backtests, scorecard, and scanner are
  computed by rules from real candles — not generated by an LLM. Same inputs → same output.
- **Abstain over guess.** During indicator warm-up the value is `null` (shown as "—"), never 0/filler.
  Missing data → HOLD or "no data", never a fabricated signal.
- **No banned phrases.** `hasBannedPhrase()` blocks "guaranteed", "sure-shot", "100% accurate",
  "risk-free", "cannot lose", etc. across every generated string (tested over 96 scans + signal/pattern JSON).
- **Confidence is computed, not asserted.** Confluence % and calibration come from the data; a 90%
  confidence is checked against actual hit-rate (calibration BO), never claimed.
- **Honest empties.** Live-data failure shows "DEMO / live unavailable: <reason>", never silent fake data.

**Test:** `node tools/test_technical.mjs` — banned-phrase scan = 0 violations; warm-up→null abstain;
opposed timeframes → HOLD; calibration buckets present. See [../evals/hallucination_eval.md](../evals/hallucination_eval.md).
