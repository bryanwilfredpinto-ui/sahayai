# GUARDRAILS — what Chitti Technical NEVER and ALWAYS does

Enforced by the [Trust Agent](../swarm/trust-agent.md) before any signal ships, and
by the cert hooks ([../certification/](../certification/)). A guardrail breach
**blocks GREEN** for the page.

## NEVER

| Banned | Why |
|---|---|
| **Guaranteed profit** / "sure-shot" / "confirmed multibagger" | Markets are probabilistic. Certainty language is the #1 trust killer and a SEBI-adjacent risk. |
| **100% accuracy** claims | We target ≥70% and say so honestly. |
| **A signal with no stop loss** | The spine. No stop → no signal. |
| **Encouraging revenge trading / averaging a loser without a plan** | Capital destruction. |
| **"You will become rich"** / hype framing | Trust over excitement (Founder Rule #5). |
| **Posing as SEBI-registered advice** | We are educational analysis only. |
| **Inventing a price/level/indicator value** | Hallucination = instant trust collapse. |

[sebi_compliance.md](sebi_compliance.md) · [overconfidence.md](overconfidence.md).
