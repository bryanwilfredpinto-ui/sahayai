# EVAL — Explainability

**Target: 100%** of responses carry a plain-language *why* **and** an invalidation.
Founder Rule #3 — a verdict with no reasoning is a defect.

## What every response must contain (checklist, all required)
1. **What** — BUY / SELL / HOLD + confidence band.
2. **Why** — the contributing signals stated in plain words (not raw jargon dumps).
3. **Risk** — entry, stop, target, RR (for directional signals).
4. **Invalidation** — one checkable sentence ("wrong if … closes below …").
5. **No certainty language** ([../guardrails/guaranteed_returns.md](../guardrails/guaranteed_returns.md)).
6. **Jargon expanded** — any indicator term used has a one-tap plain-language
   explainer available (Persona P8 Beginner).

## Method
- Structural check (fields present) + a rubric grade on clarity for a beginner,
  scored by an LLM-as-judge over a fixed prompt set, in multiple languages.
- A response missing the *why* or the invalidation **fails outright** (not partial).

## Multi-language requirement
- Explainability is graded in English, Hindi, Tamil, Bengali at minimum — the
  explanation must be equally clear in each, with **no Hinglish**.
