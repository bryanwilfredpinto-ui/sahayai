# Accessibility — Illiterate user (voice + icon-first)

**Promise:** no reading is required.

- Icon-first chips and tabs (every option has an emoji/symbol + a spoken label).
- 🔊 read-aloud on every result; auto-read of the first result for blind/illiterate profiles.
- Native-script labels via `chitti_lang.js` (26 languages) — the user hears their own language.
- Picture menus over text menus; plain, Class-5-level language in every explanation.
- "Read page" button reads the whole active panel aloud.

Verified by `tools/cert_legal_os.mjs` (icon tabs, auto-read, read-aloud button, lang switch).
