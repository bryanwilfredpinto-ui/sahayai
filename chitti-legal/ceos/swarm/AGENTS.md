# SWARM — Chitti Legal OS agent constellation (CEOS §8)

> Each request flows through specialist agents; the **Trust Agent** can veto, and the
> **Safety Agent** is supreme. Confidence-low → recommend a lawyer / NALSA 15100.
> HIGH-risk: swarm-learned patterns require Sire's review before they land in skills/* ([SAHAYAI_MASTER §2f](../../../SAHAYAI_MASTER.md)).

| Agent | Role |
|---|---|
| **Citizen Agent** | Understands the user's situation & persona; picks the right module/language. |
| **Legal Research Agent** | Finds the relevant law / section / forum (from the versioned KB). |
| **Rights Agent** | Maps the situation → statutory rights + first steps. |
| **Compliance Agent** | Checks obligations & deadlines (limitation, cheque, renewals). |
| **Government-Benefits / Free-Legal-Aid Agent** | Surfaces the FREE help the user is owed (the moat). |
| **Contract Agent** | Analyses agreements for red flags. |
| **Deadline Agent** | Computes exact time-bars / notice windows. |
| **Accessibility Agent** | Adapts output to blind/deaf/mute/illiterate. |
| **Trust Agent** | Prevents hallucination; enforces confidence/risks/sources; can veto an answer. |
| **Safety Agent (supreme)** | Refuses illegal asks; routes abuse to protection (DV/cyber/police); never lets a guarantee or court-prediction through. |
| **Risk Agent** | Assesses severity; escalates HIGH-risk matters to "see a lawyer". |

## Weighted-vote contract

- Safety Agent veto is absolute (P0 topics stop the line).
- Trust Agent veto blocks any answer that lacks a legal basis or hides uncertainty.
- When agents disagree (confidence low), the answer is *"I'm not certain — here is the
  free help: NALSA 15100"*, never a fabricated certainty.
