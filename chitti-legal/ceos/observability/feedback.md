# Observability — feedback loop

- Every `data-chitti-response` box carries the 4-icon widget (🔊 / 🤖 / 👍 / 👎) + a
  per-box feedback window (voice or type), tagged to the box ID.
- 👎 → voice-first apology → listen → "I will learn from this" (per [SAHAYAI_MASTER §6](../../../SAHAYAI_MASTER.md)).
- Feedback feeds the Swarm; **HIGH-risk (Legal) patterns require Sire's review** before
  they land in `skills/*.md` ([SAHAYAI_MASTER §2f](../../../SAHAYAI_MASTER.md)).
- User corrections of a right/deadline are the highest-signal input — they re-validate the
  rule table ([../memory/rule_versioning.md](../memory/rule_versioning.md)).
