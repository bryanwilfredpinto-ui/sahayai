Chitti Health File — disclaimer

Chitti Health File is a document organiser with extraction + reminder + share helpers. It is not a doctor, not a pharmacist, not a diagnostic system. Every extracted value should be confirmed against your original document. Out-of-range flags are heuristics, not diagnoses.

Privacy: documents are AES-256-GCM encrypted with a per-user key derived from your user_token + a server-side pepper. Loss of either = total inability to decrypt; this is intentional. We never share with anyone without your spoken "haan" on each share.

DPDP Act 2023 compliance: grievance officer sire@sahayai.in. Voice consent is treated as valid consent for the consent gate.

No AI training: health images sent to DeepSeek for extraction are opted out of training input retention (per DeepSeek API ToS default).
