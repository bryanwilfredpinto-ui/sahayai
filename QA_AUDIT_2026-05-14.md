## Fixes applied (code)

All shared substrate changes route through `chitti_a11y.js`, which is already loaded by every Chitti product page — one edit propagates to all 12.

### 1. `chitti_a11y.js` — added **Explain simply** button
The bar already injected language picker + speak + Braille + ISL controls. Added a **💡 Explain simply** button that:
- Re-renders every `<p>`, `<li>`, `.explanation`, `.narr`, `.plain-english` block in short, plain-English sentences (≤14 words, parentheticals stripped, clause-split on `, ; and but because so that which`).
- Idempotent — clicking again restores the original DOM.
- Announces via the shared aria-live region (Braille displays mirror).

Public API exposed: `Chitti.a11y.explainSimply()`.

### 2. `chitti_a11y.js` — added **🎬 Demo** button
- Looks up `<meta name="chitti-demo-sample" content="…">` for a per-page sample.
- Else uses the page title as a fallback sample query.
- Pre-fills the page's first visible `textarea / input[type=text|search]` (or any element marked `data-chitti-demo-target`).
- Fires `input` + `change` events so the page's existing handlers kick in.
- If page has no input (status dashboards), announces "this page has no input — use the speaker to hear live data".

Public API exposed: `Chitti.a11y.runDemo()`.

### 3. `chitti_news.html` — added sticky news disclaimer
- New `.news-disclaimer` sticky bar at `z-index:55` above the existing picker bar.
- Text: "Chitti News aggregates RSS sources — verdicts cross-reference ≥2 sources. Always verify with the original source before sharing."

### 4. `chitti_voice_factory.html` — added sticky honest-ledger disclaimer
- New `.vf-disclaimer` sticky bar (saffron-on-navy palette).
- Text: "Honest ledger · Tier C languages are donor-required — never silently fall back. Mock supplier is labelled `mock_bhashini`, not `bhashini`."

### 5. `scripts/audit_chitti_pages.sh` — repeatable QA script
- 10 criteria × 12 pages, runs in <1s, deterministic.
- Patterns recognise both page-local markers and shared-substrate inheritance (e.g. a page passes LANG via `chitti_a11y.js`).
