## The shift in question

The user should **never** ask:

> *"What happened?"*

The user should ask:

> *"What should I know?"*
> *"What should I do?"*
> *"What does this mean for me?"*

CNOS exists so the second set of questions has a free, vernacular, trustworthy answer for every Indian reader, every day.

---

## Optimize for (in order)

| # | Dimension | What it means in CNOS |
|---|---|---|
| 1 | **Trust** | Every claim cites a real source URL; verified-by-N-sources badge; fact-check verdict |
| 2 | **Accuracy** | Category classifier F1 ≥ 0.95; source attribution F1 ≥ 0.99; verification F1 ≥ 0.95 |
| 3 | **Explainability** | Every classification + verdict carries a `why` trail (rule + source + confidence) auditable in <1 tap |
| 4 | **Accessibility** | A+ four-user contract (Blind / Deaf / Mute / Illiterate) on every card, every page |
| 5 | **Personalization** | State-aware, language-aware, profession-aware, history-aware — all on-device |
| 6 | **Actionability** | Every story answers "should I care?" + "what next?" — not just "what happened?" |
| 7 | **Career Outcomes** | Cross-handoff to CNAIOS for any story with profession-relevance |
| 8 | **Speed** | Feed render < 2 s on 4G; < 12 s on 2G; Trust Strip visible in < 2 s |
| 9 | **Transparency** | Coverage payload narrates gaps honestly; staleness flag on >30-day items; classifier mode visible |
| 10 | **Intelligence** | 7-agent swarm — every story passes News → Verification → Context → Personalization → Accessibility → Career → Action |

## Definition of done — for ANY feature in CNOS

Every feature must pass, in order, before it is considered complete:

> **Read → Skill → SOP → Swarm → Guardrails → Evals → Observability → Accessibility → Memory → Certification**

If any stage fails, the feature is RED. No green without all 10 stages passed.

## What I will never do

- Recommend an unverified story for "engagement"
- Hide reading time
- Auto-play video
- Label a story partisan
- Lock content behind a paywall
- Track readers off-device
- Translate-and-ship without a vernacular publisher's source
- Surface a verdict without ≥2-source corroboration
- Show "Verified" without showing what verified it
