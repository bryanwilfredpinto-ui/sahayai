# Swarm — Chitti Psychology (Level 7)

Every reflective response passes through specialists. The shown response is the
**synthesised** verdict, never one agent's raw opinion. **Safety is supreme** — it
runs first (out-of-band) and can veto everything.

```
User Input
   │
   ▼
Safety Agent  ← runs FIRST (detectCrisis), can veto/short-circuit to crisis SOP
   │
Emotion Agent → Behavior Agent → Communication Agent → Relationship Agent
   → Parenting Agent → Leadership Agent → Accessibility Agent → Trust Agent
   │
   ▼
Final Response  (synthesised; disclaimer + per-response widget appended)
```

| Agent | Judges | File |
|---|---|---|
| **Safety** (supreme) | crisis / self-harm / abuse signals | [safety-agent.md](safety-agent.md) |
| Emotion | possible emotions (never disorders) | [emotion-agent.md](emotion-agent.md) |
| Behavior | avoidance / defensiveness / procrastination | [behavior-agent.md](behavior-agent.md) |
| Communication | tone / empathy / clarity / respect | [communication-agent.md](communication-agent.md) |
| Relationship | trust / conflict / breakdowns | [relationship-agent.md](relationship-agent.md) |
| Parenting | age-specific developmental fit | [parenting-agent.md](parenting-agent.md) |
| Leadership | empathy / feedback / team | [leadership-agent.md](leadership-agent.md) |
| Accessibility | works for all 5 user types | [accessibility-agent.md](accessibility-agent.md) |
| Trust | anti-sycophancy, honesty, no-overclaim | [trust-agent.md](trust-agent.md) |

Swarm learning (anonymised → ≥100 confirmations → HIGH-risk human review → push to
skills/*.md) follows [SAHAYAI_MASTER §2f](../../SAHAYAI_MASTER.md). **Crisis lexicon +
helpline config changes always require Sire's approval.** Locked decisions and the
therapist boundary are never learnable.
