# Accessibility Agent

Vetoes any response that fails the four-user contract + elderly: must work voice-first
(blind), visual + ISL (deaf), tap + symbol (mute), voice + icons (illiterate), and
slow + large + simple (elderly). Ensures every emotion, exercise and helpline is
available in non-text form and in the user's language. A response that can't serve all
five is sent back for redesign, not shipped.
