# Accessibility — Blind user (voice-first)

- Every response box reads aloud (🔊 + auto-read on first visit); `aria-live` regions.
- Emotions are **named by voice**; the emotion picker is spoken, selectable by voice.
- Breathing / grounding exercises are **audio-led** (5-4-3-2-1 works perfectly eyes-closed).
- Never say "see this" / "tap the form"; describe everything; audio-first navigation.
- Crisis path: helplines spoken + large `tel:` buttons; Chitti stays on until dialled.
- Verified via TalkBack/VoiceOver walkthrough (Sire's slot) + `chitti_a11y.js` substrate.
