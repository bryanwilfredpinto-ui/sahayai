# Accessibility — Mute user (tap-first)

- Whole flow works by **tap**: emoji/symbol mood grid, tap-to-pick emotion, tap-to-start
  exercise. Voice-out on; voice-in optional.
- Text input fully supported; re-confirm intent more often (no spoken correction).
- Crisis path reachable entirely by tap; family-cascade alert by tap with Golden-Rule
  confirm (tap Yes/No, never voice-required).
