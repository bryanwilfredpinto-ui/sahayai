# Accessibility — Illiterate user (voice + icons)

- **Nothing requires reading.** Everything is spoken; menus are pictorial.
- **Vernacular emotion lexicon + icons** so the user can name a feeling without words —
  the core accessibility unlock (affect labeling for non-readers).
- Exercises are voice-guided; the journal is voice-journaling.
- 2G-ready (deterministic engine works offline; no heavy assets).
- Crisis helplines spoken aloud + icon `tel:` buttons; Chitti reads the number digit by
  digit and offers to dial (with confirm).
