# Accessibility — Deaf user (visual-first)

- Full **text + emotion symbols** for every response; nothing audio-only.
- **ISL animation panel** on every response (`chitti_isl.js`); tap-word modal.
- Crisis escalation never relies on a phone call — surface text/WhatsApp helplines
  (Vandrevala WhatsApp) and visual family-cascade, not telephone-only.
- High-contrast, captioned exercises (breathing shown as an animated pacer).
- Serves India's ~6-crore deaf population — a category first.
