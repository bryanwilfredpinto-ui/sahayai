# OBSERVABILITY — Chitti Psychology (Level 11 index)

> What we watch — privacy-first. We track **patterns, never content**. Emotional data
> never leaves the device; observability is anonymised aggregates only.

## Tracked (anonymised, on-device-first)

- emotional **topics** (categories, not text) and feature usage
- **crisis escalation** count + warm-handoff completion (the metric that matters most)
- **false-positive crisis rate** (kept low so users aren't needlessly alarmed)
- accessibility-mode usage (voice / symbol / ISL) — proves the floor is used
- coping-exercise completion rate
- per-response 👍/👎 + negative-signal rate ("Chitti felt cold / preachy / sycophantic")
- user satisfaction

## Never tracked

- ❌ journal/conversation **content** (stays on device)
- ❌ session length as a success metric (dependency anti-metric)
- ❌ any personal identifier without explicit consent
