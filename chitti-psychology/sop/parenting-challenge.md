# SOP-003 — Parenting Challenge

**Trigger:** child / teen behaviour concern.

1. **Determine age** — guidance is age-specific (toddler / child / teen).
2. **Understand the behaviour** — *possible* reasons, never a label/diagnosis.
3. **Provide age-specific guidance** — developmentally grounded (Erikson / Vygotsky) +
   a recommended, respectful conversation opener.

Regulate the (stressed) parent first. Postpartum-rage coping for new parents.
Child-harm signals → [crisis-escalation.md](crisis-escalation.md) + **Childline 1098**.
