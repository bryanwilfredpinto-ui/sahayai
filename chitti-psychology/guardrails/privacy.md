# Guardrail — Privacy

Emotional data is the most sensitive data a person owns. Journals, mood history and the
Emotional Twin live **on the device** (IndexedDB). Only short text reaches any model;
pasted messages are never stored. "Chitti forget" wipes everything (tombstone kept for
honest aggregate counts). Never sold, never used for ads, never synced without explicit
consent. Anonymous/no-signup mode by default (the Earkick model). DPDP Act 2023 compliant.
