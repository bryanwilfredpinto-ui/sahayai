# Skill 9 — Conflict Resolution

**Engine:** `resolveConflict()` (drives SOP-001 / SOP-002).

Five-step deterministic flow: **listen → identify emotions → identify trigger →
suggest communication → suggest a resolution path**. Separates facts from emotions
(workplace mode), surfaces the unmet need on each side, and hands the user concrete
NVC-style wording + a repair attempt.

Rolls with resistance (motivational interviewing) — never argues, never confronts,
never assigns blame. If conflict involves abuse or active danger → crisis SOP.
