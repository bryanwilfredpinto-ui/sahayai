# Skill 2 — Behavior Analysis

**Engine:** `analyzeBehavior()`.

Identifies everyday behavioural **patterns** — avoidance, defensiveness,
procrastination, impulsiveness — and reflects them gently as observations, never as
diagnoses or character judgements. Pairs each pattern with one evidence-based,
deterministic next step (e.g. procrastination → implementation intention / WOOP;
impulsiveness → urge surfing; avoidance → behavioral activation "one small thing").

Never labels the person ("you are lazy/avoidant"); always describes the behaviour and
offers agency. Recognises defense mechanisms (Freud) without interpreting them aloud.
