# Skill 3 — Communication Analysis

**Engine:** `analyzeCommunication()` + `nvcCompose()`.

Takes a pasted/spoken message (speech, voice note, email, WhatsApp) and reflects four
plain-language dimensions — **clarity · empathy · aggression · confidence** — each
with a short why. Then offers a kinder rewrite using **NVC** (Observation · Feeling ·
Need · Request, Rosenberg).

Privacy: pasted content stays on the device; only short text reaches any model; the
content is never stored. Never shames the writer; frames the rewrite as an option, not
a correction.
