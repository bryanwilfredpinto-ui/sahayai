# GUARDRAILS — Never-Hallucinate Fields

The fields below are **never** generated by an LLM or guessed by heuristic. Each one has a verified source, a stored copy in the `medupi.*` schema, and a graceful "unknown" path when the source is silent. If any of these ever appears with a fabricated value in production, that is a P0 incident.

---

## 1. MRP (Maximum Retail Price)
- **Source of truth:** The MRP printed on the medicine pack as captured in the seed dataset (Apollo Pharmacy CSV, 211,207 rows in `medupi.medicines`).
- **Stored column:** `medupi.medicines.mrp` (numeric, currency `INR`).
- **Never:** Computed via "if Jan Aushadhi is X then MRP is roughly Y."
- **Unknown path:** Return `null`; UI renders "MRP not on record" in EN / HI; user types it manually if needed.
- **Audit:** Loader runs logged in `medupi.loader_run` with `source='apollo_csv'`.

---

## 2. Manufacturer name
- **Source of truth:** Apollo Pharmacy CSV + BPPI products (for Jan Aushadhi generics) + Kaggle branded dataset where present.
- **Stored column:** `medupi.medicines.manufacturer`.
- **Never:** Inferred from brand-name pattern matching (no "starts with `Cipla-` so manufacturer is Cipla" logic).
- **Unknown path:** Return `null`; UI renders "manufacturer not on record."
- **Audit:** Vision extraction can read the manufacturer off the strip but the value is reconciled against the stored row before display.

---

## 3. Jan Aushadhi price
- **Source of truth:** Official BPPI product list (Pharmaceuticals & Medical Devices Bureau of India).
- **Stored column:** `medupi.medicines.jan_aushadhi_price`.
- **Never:** Computed as "MRP × 0.3" or any percentage of branded MRP. The official BPPI MRP is the only valid value.
- **Unknown path:** Return `null`; alternative card omits the Jan Aushadhi line; never shows "approximately ₹X."
- **Audit:** `medupi.loader_run` with `source='bppi_products'`.

---

## 4. Jan Aushadhi store address
- **Source of truth:** Official BPPI store list with lat/lng + state + district + pincode.
- **Stored table:** `medupi.jan_aushadhi` (one row per store).
- **Never:** Geocoded from a free-text address. Never synthesised from a city centroid.
- **Unknown path:** Empty list when haversine finds nothing in radius; by-state fallback uses only loaded rows; never invents.
- **Audit:** `medupi.loader_run` with `source='jan_aushadhi'` records the load timestamp + row count.

---

## 5. Salt composition
- **Source of truth:** Apollo Pharmacy CSV → cross-referenced against RxNorm enrichment (where loaded) for canonical form.
- **Stored column:** `medupi.medicines.salt_composition` (lower-case, `+`-joined combinations).
- **Never:** Inferred from brand name (no "Crocin so salt is paracetamol" logic in code — the lookup is by stored row).
- **Vision path:** When the LLM extracts a salt from a strip photo, it is *reconciled* against the DB row before being used for the strict-match query. If the extracted salt is not in the DB, the user is shown the extracted text and asked to confirm.
- **Unknown path:** Return `null`; route the user to type the medicine name; never proceed to alternatives with an unknown salt.

---

## 6. Dosage form
- **Source of truth:** Apollo Pharmacy CSV — enumerated to 8 values: Tablet / Capsule / Syrup / Injection / Inhaler / Cream / Drops / Sachet.
- **Stored column:** `medupi.medicines.dosage_form`.
- **Never:** Free-text. Never inferred from pack-size string.
- **Unknown path:** Return `null`; strict-match query cannot proceed without a form match — UI prompts the user to specify.

---

## 7. Prescription-required flag
- **Source of truth:** CDSCO scheduled-drug list (Schedule H / H1 / X mapping).
- **Stored column:** `medupi.medicines.prescription_required` (boolean) + `schedule` (string).
- **Never:** Inferred from risk-class alone. A LOW-risk molecule can still be Schedule H if CDSCO says so.
- **Unknown path:** Default to `true` (safe side) with a flag indicating "schedule not on record"; UI surfaces "treat as prescription-only."
- **Audit:** `medupi.loader_run` with `source='cdsco'`.

---

## 8. NPPA ceiling price
- **Source of truth:** NPPA-notified ceiling-price list (DPCO 2013 schedule).
- **Stored column:** `medupi.medicines.nppa_ceiling_price`.
- **Never:** Computed from MRP. Never extrapolated across molecules.
- **Unknown path:** Return `null`; alternative card simply omits the NPPA line — never renders "approximately."
- **Audit:** `medupi.loader_run` with `source='nppa'`; NPPA list is refreshed quarterly by Bryan; refresh cadence logged.

---

## Cross-cutting rule: confidence + freshness on every uncertain value

Even where a value is sourced cleanly, two metadata fields ride along:

- **`confidence`** — only on vision-extracted fields (LLM self-rated `high|medium|low`). Frontend gates low-confidence reads with an amber warning and a "type it instead" CTA.
- **`freshness`** — on live Brave snippet prices (pharmacy snippets older than 7 days are tagged stale, in red, with the symbol and EN/HI caption).

Never fabricate either. The values flow through the pipeline; the UI honours them.
