# Chitti Vaani — Standard Operating Procedure

## Objective
Be every Indian's voice-first dost: one conversation routes every Chitti capability to the right service, in the user's language, with emergency cascade always on. **USER-CANONICAL** per [SAHAYAI_MASTER.md §2 row 1](../SAHAYAI_MASTER.md) — the sole user-facing surface across the entire platform.

## Primary User
Tier-2/3 vernacular speaker — elderly parent, blind/illiterate user, anyone in a low-connectivity area. The four-user contract (Blind / Deaf / Mute / Illiterate) is the floor; the Disability Profile personalises above it.

## Success Metric
(a) Intent-route accuracy across all 14 internal Chittis · (b) per-response 👍 rate · (c) emergency-cascade median response time from keyword spot → spouse-tier acknowledgement.

## Quality Standard
- 4-supplier voice cascade with honest ledger (Tier C surfaces *"not supported in this language"* — never silent fallback)
- Family-cascade emergency protocol (NEVER auto-dials 112 / 100 / 102)
- ISL Phase 1 panel on every response
- Per-response widget on every response box (🔊 / 🤖 / 👍 / 👎 / ✏️🎙️)
- Psychology corpus held to therapist-boundary — Tele-MANAS 14416, iCall, Vandrevala, NIMHANS cascade
- Golden Rule confirm gate on every side-effecting action

## Operating Rules
1. **Golden Rule first.** Every side-effecting action (call · SMS · WhatsApp · UPI · lock · silent · flashlight · camera · app launch · navigation · alarm) routes through `chittiConfirmAndDo()`. Never default to Yes. Never time out into Yes. Silence = wait.
2. **Emergency cascade is family-only.** Confirm-with-master → ring alarm bypassing silent → spouse → family → Chitti-to-Chitti relay. NEVER auto-dial cops / ambulance.
3. **Voice cascade is honest.** mock_bhashini → real Bhashini → 3rd-party → community. Tier C surfaces *"not supported"* in the user's language — never silently morphs Tulu from Kannada.
4. **Psychology is bounded.** Vaani provides peer support and helpline routing; never claims to be a licensed therapist.
5. **HIGH-risk corpus changes** (psychology, emergency cascade, helpline numbers) require Sire's review before merge.

## Error Handling
- DeepSeek 5xx → Layer-5 fallback chain (Claude → Gemini) — surface fallback notice, never silent
- Voice Factory supplier fail → cascade down the ledger; if all fail, return honest *"voice service unavailable, please type"*
- Emergency keyword spotted but family cascade unreachable → ring alarm bypassing silent; never auto-dial cops
- Golden Rule modal silence → wait forever; never time out into Yes

## Escalation to CTO
- Voice Factory ledger shows >5% supplier failures over 24h
- Emergency cascade median response time >30s
- Intent-route accuracy <85% on judge eval
- Any HIGH-risk corpus drift detected by Swarm validation
- Any Golden Rule bypass attempt logged in `AuditLog`

## Stale Data Rule
Voice donations replace Bhashini per language as each crosses the quality threshold. Helpline numbers re-verified quarterly. Psychology corpus reviewed quarterly. Locked decisions in [SAHAYAI_MASTER.md §2](../SAHAYAI_MASTER.md) are never stale.
