# Chitti Vaani — frontend

Single static page. Served either from the workspace root (`/chitti_vaani.html` on sahayai.in) or from this folder.

`index.html` is a **mirror** of the canonical `chitti_vaani.html` at the repo root. Edit the root file; copy here when shipping.

To point the page at a non-default backend, append `?api=https://my-host` to the URL.
