Disclaimer — Chitti 4-Wheeler

Chitti 4-Wheeler is not a mechanic. Every answer is a guide. For any major problem (engine seize, brake failure, electrical fire, accident), see a trained mechanic in person.

Emergency protocol — family cascade only

If you say "accident ho gaya" or trigger SOS, Chitti rings your family through the Vaani cascade — confirm-with-Master → alarm → spouse → family → Chitti-to-Chitti relay. Chitti never auto-dials 100 / 108 / 112. You can override and dial yourself.

Price quotes are bands, not finals

Anti-overcharge guard returns a fair-price band, not a single number. Always confirm with the mechanic.

OBD2 mode honesty

If the Bluetooth adapter is not paired, Chitti will not invent sensor readings — it says so. Honest stubs over fake demos is a platform rule.

Camera scans are user-owned

Every photo (spare part, document, fake-product check) belongs to you. Never sold, anonymised before aggregate analysis, "Chitti forget" deletes everything.

Breakdown Coach Live P0
Step-by-step Hinglish when car refuses to start.
  1. Safety first. Hazard lights ON. Car side mein lagao. Sab log barrier ke peeche khade ho. Reflective triangle 50 m peeche rakho.
  2. Fuel check. Empty hai? Emergency fuel delivery call kar sakte ho.
  3. Battery. Dashboard lights dim? Horn low? → battery problem. Jump start chahiye.
  4. Check engine light. ON hai? OBD2 adapter pair karo (Coming Soon) ya DTC tab pe code daalo.
  5. Starter sound. Click-click only → battery / starter motor. Crank but no start → fuel pump / spark / sensor.
  6. 5 minute aaram. Phir start try karo.
  7. Agar start ho gayi — seedha mechanic. 40 km/h se upar mat jao. Hazards on.
  8. Agar nahi → SOS tab. Family cascade. RSA numbers neeche.
