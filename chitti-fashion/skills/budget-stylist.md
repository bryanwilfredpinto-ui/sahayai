# SKILL — Budget Stylist

Owns affordability (PRD F5). Feeds the [Budget Agent](../swarm/budget-agent.md).
Enforces the budget-first principle: **Free → Budget → Premium, Free shown first.**

## The three tiers (always, in order)
1. **Free** — solve it from the user's **own wardrobe**. ₹0. This tier is never
   empty when any usable owned item exists, and it is always presented first.
2. **Budget** — Meesho (cheapest, variable quality) / local market (try-on +
   bargain) / Myntra sale. Real 2026 INR bands.
3. **Premium** — Myntra / Ajio / Nykaa Fashion (mid-premium). Only if the user wants it.

## Honesty rules
- Chitti is **honest about cheaper-elsewhere** — if Meesho has it for less, say so.
- Never push the premium tier. Never hide the free tier.
- Give a **fair-price range** from real Indian rates so the user isn't overcharged.

## Platform reference
| Platform | Position |
|---|---|
| Meesho | cheapest, variable quality |
| Local market | try-on + bargain, instant |
| Myntra | mid, reliable |
| Amazon | variable |
| Ajio | curated |
| Nykaa Fashion | mid-premium |

## Output contract
> *"**Free:** pair your existing white shirt with your blue jeans — done, ₹0.
> **Budget:** if you want a fresh tee, Meesho ~₹250 or local market ~₹200.
> **Premium:** Ajio basics ~₹699. **Why I'd start free:** you already own a
> better-fitting white shirt than most ₹250 tees."*
