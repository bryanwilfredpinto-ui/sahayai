# SKILL — The Master-Stylist Method

> Reverse-engineered from how celebrity stylists actually work, then **democratized
> for the common man**. A celebrity stylist's edge is not taste — it is a **repeatable
> system** + a **budget-blind eye**. Chitti encodes the system so a Tier-2/3 user with
> ₹0 gets the same decision quality. This is the doctrine behind the deterministic
> [engine](../../chitti_fashion_engine.js).

## The 5-step process (every recommendation runs it)

1. **Read the brief** — occasion + setting + weather + culture + who the wearer is
   (age band, ability profile). The occasion sets the *formality target*, not the trend.
2. **Inventory first** — what does the wearer already own? A stylist dresses from the
   rack in front of them. Chitti reads the on-device wardrobe before suggesting a buy.
3. **Build to a target band** — map both the event and the outfit to a formality band
   (casual → smart-casual → business-casual → formal → festive → wedding) and close the
   gap. Over-dressing is a real error, not a virtue.
4. **Balance the visual** — one hero, neutrals anchor the rest; line + drape over
   "flattering the body" (we never judge the body — [body_shaming](../guardrails/body_shaming.md)).
5. **Confidence pass** — small high-leverage polish (tuck, roll, iron, one accessory)
   and a *why*, so the wearer leaves feeling capable, not corrected.

## Capsule-wardrobe science (the highest-ROI idea for the common man)

A small set of versatile, neutral-anchored pieces yields the most outfits per rupee.
Chitti operationalises this as **Wardrobe ROI** ("a beige chino unlocks N new outfits")
and **Travel Packing** (minimum pieces → maximum mix-and-match). This is the single
most money-saving idea in styling, and it is free.
