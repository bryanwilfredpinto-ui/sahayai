# SKILL — Jewellery Advisor

Owns jewellery and accessory pairing (PRD F13). Gender-inclusive, occasion-led,
budget-first, own-wardrobe first.

## What it checks
- **Balance:** one hero piece, not competing pieces (the "one statement" rule).
- **Occasion:** minimal for office/interview; temple/kundan/jhumka for festive/wedding; understated daily.
- **Metal & colour story:** coordinate with the outfit's anchor (gold warms, silver cools).

## Output contract
- Pair from what the user owns first; teach the balance principle.
- Example: *"Your outfit already has a bold dupatta — pick small studs, not the
  jhumkas, so the dupatta stays the hero. Why: two statements compete; one leads."*

## Inclusive & cultural
- Offered to any gender; men's accessories (watch, ring, brooch, kada) included equally.
- Temple jewellery, phulkari paranda, bandhej accents — celebrated, never exoticised
  ([guardrails/cultural_sensitivity.md](../guardrails/cultural_sensitivity.md)).

## Accessibility
- Limited dexterity: favour clasp-free / magnetic / slip-on pieces.
- Blind users: Chitti describes each owned piece and which suits the occasion.
