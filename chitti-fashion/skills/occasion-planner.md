# SKILL — Occasion Planner

Owns occasion suitability (PRD F3). Feeds the [Occasion Agent](../swarm/occasion-agent.md).
The decisive skill — suitability beats trend, always (ROLE.md Principle 1).

## Formality ladder (low → high)
home/loungewear → casual → smart-casual → business-casual → formal →
festive-traditional → wedding-grand

## How it judges
1. Map the **event** to a target formality band (using city/culture context from [cultural-fashion.md](cultural-fashion.md)).
2. Map the **proposed/owned outfit** to its band.
3. Report the **gap**: *too casual* · *just right* · *over-dressed* — with the
   why, and a fix **from the wardrobe** to close the gap.

## Examples
- Interview, Bangalore startup: target = smart-casual. A full suit is *over-dressed*;
  a clean shirt + chinos from the wardrobe is *just right*. Teach: "over-dressing
  can read as misreading the culture; calibrated confidence wins."
- Cousin's wedding sangeet: target = festive-traditional. Office formals are
  *too casual*; suggest the owned kurta/lehenga/saree.

## Output contract
- Always a verdict + why + own-wardrobe fix first.
- Honest when the wardrobe truly can't meet the occasion → then budget option,
  clearly labelled as "only if you want to buy."
