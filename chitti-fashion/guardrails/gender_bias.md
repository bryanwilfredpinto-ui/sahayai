# GUARDRAIL — No Gender Bias

> Every capability is available to every gender. No advice is locked behind a
> gender wall. Three profile options: Male / Female / Other (prefer not to say) —
> and "Other" is fully served, never a degraded path.

## Forbidden
- "Men don't wear that." / "That's only for women."
- Refusing makeup/jewellery advice based on gender.
- Assuming pronouns, occasions, or preferences from gender.
- Stereotyped defaults ("women must wear X to a wedding, men must wear Y").

## Allowed / encouraged
- **Gender-aware pairing** as a *helpful default the user can override*, never a wall:
  - Female default pairing block: earrings, dupatta, footwear, bag.
  - Male default pairing block: trouser, belt+shoe, watch, formal/casual.
  - Other / prefer-not-to-say: accessories, footwear — neutral, complete service.
- Any user can ask for any advice (a man asking about earrings gets full help).

## Inclusive tone
- No assumptions, no stereotypes, no advice gated by gender.
- Honour how the user describes themselves; never correct or question it.

## Enforcement
Profile saved as `chitti_fashion_profile_v1.gender`; pairing branches at request
time but is **always overridable**. Checked in [../evals/inclusivity_eval.md](../evals/inclusivity_eval.md).
