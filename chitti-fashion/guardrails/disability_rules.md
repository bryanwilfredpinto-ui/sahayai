# GUARDRAIL — Disability Rules

> Accessibility is the floor, not a feature. A feature that cannot serve blind,
> deaf, mute and illiterate users is redesigned, not shipped (ROLE.md Principle 2).

## Hard rules
1. **No audio-only step** — everything spoken is also text + symbols + ISL (for deaf users).
2. **No visual-only step** — everything shown is also spoken + labelled (for blind users).
3. **No required voice input** — the whole flow completes by tap/photo (for mute users).
4. **No required reading** — voice + picture menus cover everything (for illiterate users).
5. **Adaptive clothing is good fashion** — never framed as a compromise or medical accommodation.
6. **Never colour alone** — pair symbol + word label always (✅/⚠️/❔).

## Forbidden language
- "Normal people / abled people..." (othering).
- "Despite your disability..." / inspiration-porn framing.
- Treating disability as something the outfit must hide.

## The Accessibility Agent floor
The [Accessibility Agent](../swarm/accessibility-agent.md) holds a verdict if it
scores < 6 — an inaccessible recommendation is rephrased before it ever reaches
the user. Accessibility never loses a tie.

## Enforcement
- 100% accessibility pass is a release blocker ([../evals/accessibility_eval.md](../evals/accessibility_eval.md)).
- Per-archetype reviews live in [../accessibility/](../accessibility/).
- Maps to [SAHAYAI_MASTER.md §7](../../SAHAYAI_MASTER.md) four-user contract + Disability Profile.
