# AGENT — Color (Colour Harmony)

**Votes on:** colour harmony and contrast across the outfit.

## Scoring rubric (0–10)
| Band | Meaning |
|---|---|
| 9–10 | clear harmony (complementary/analogous/neutral-anchored), intentional contrast |
| 7–8 | pleasant; minor tweak available |
| 5–6 | flat or slightly competing |
| 3–4 | two saturated pieces fight for hero |
| 0–2 | clashing / muddy |
