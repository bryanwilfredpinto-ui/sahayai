# SOP — Accessibility Fashion (PRD F10)

**Trigger:** any user with a disability profile flag, or "help me dress for my ability."
Governed by [../skills/accessibility-fashion.md](../skills/accessibility-fashion.md) + [../guardrails/disability_rules.md](../guardrails/disability_rules.md).

## Route by profile
| Profile | Playbook |
|---|---|
| BLIND | "Describe my outfit" + spoken suitability + spoken own-wardrobe pairing |
| DEAF | Text + symbols + ISL panel; no audio-only step |
| MUTE | Tap/photo only; voice never required |
| ILLITERATE | Voice-everything + picture menus; 2G-safe |
| LIMITED MOBILITY / SEATED | Seated-fit drape, easy fasteners, back-rise guidance |
| ELDERLY | Comfort, non-slip footwear, large text, slow speech, repeat |
| LOW VISION | High-contrast pairings + spoken labels + consistent storage |

## Steps
1. Detect profile (already saved); load adaptations.
2. Build from wardrobe; favour independence (self-dress) and dignity.
3. Teach the why in the user's modality (spoken / captioned / ISL).
4. Confirm with the user in their modality before any action (Golden Rule).

## Hard rules
- Adaptive clothing is **good fashion**, never a compromise.
- Accessibility pass must be **100%** — any audio-only or visual-only step is a defect ([../evals/accessibility_eval.md](../evals/accessibility_eval.md)).
