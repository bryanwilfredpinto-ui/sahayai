# SOP — Festive Fashion (PRD F9)

**Trigger:** "what do I wear for Diwali / Eid / Pongal / Onam / Holi / Karva Chauth / Christmas / Baisakhi?"

## Steps
1. **Festival → spirit** — map to palette + formality ([../skills/cultural-fashion.md](../skills/cultural-fashion.md) festival table).
2. **Region/community nuance** — respect local norms; ask if unsure ([../guardrails/cultural_sensitivity.md](../guardrails/cultural_sensitivity.md)).
3. **Wardrobe first** — build from owned festive wear + jewellery + footwear.
4. **Comfort + duration** — long pujas/gatherings: comfortable, weather-safe, dance-friendly where relevant.
5. **Budget tiers** — only if needed; reuse + small accent buys beat a whole new outfit.

## Hard rules
- Celebrate every festival's tradition; never rank one community's dress above another.
- Holi: nothing precious. Karva Chauth: traditional red/maroon respected. Onam/Pongal: white+gold.
- Inclusive: festive dressing offered to every gender equally.

## Output
Festival-matched owned outfit + jewellery/footwear + comfort note + cultural why.
