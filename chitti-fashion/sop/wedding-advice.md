# SOP — Wedding Advice (PRD F3 / F9)

**Trigger:** "what do I wear to a wedding / sangeet / reception / mehendi?"

## Steps
1. **Closeness** — own / sibling / close friend / colleague? Sets the formality ceiling (see [../skills/cultural-fashion.md](../skills/cultural-fashion.md) hierarchy).
2. **Function** — mehendi (playful/bright) · sangeet (festive/dance-friendly) · wedding (grand-traditional) · reception (formal-glam). Each has a different target.
3. **Region/community** — adjust dress norms respectfully ([../guardrails/cultural_sensitivity.md](../guardrails/cultural_sensitivity.md)).
4. **Wardrobe first** — build from owned festive wear (lehenga/saree/sherwani/kurta + owned jewellery).
5. **Comfort + duration** — long events: dance-friendly, weather-safe, footwear you can stand in.
6. **Budget tiers** — only if the wardrobe can't meet the function: Free → Budget → Premium.

## Hard rules
- Never imply the user must "outshine" or compete — confidence, not comparison.
- Respect "don't wear white/black/red" community sensitivities; ask if unsure rather than assume.
- Accessibility: seated guests → comfortable drape; seniors → easy fasteners + stable footwear.

## Output
Function-matched outfit from wardrobe + jewellery/footwear pairing + comfort note + why.
