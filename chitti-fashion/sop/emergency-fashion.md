# SOP — Emergency Fashion (PRD F14)

**Trigger:** "I have 5 minutes and an event — dress me NOW" / one-tap emergency button.

## Steps
1. **Speed mode** — single round-trip, single best owned outfit. No browsing.
2. **Constraints honoured** — clean (not in `last_worn`=today/laundry), weather-fit, occasion-fit.
3. **One outfit, decided** — present the fastest acceptable owned combo; offer one swap only.
4. **Spoken in one breath** — for blind/illiterate users: "Grey kurta, black pants, brown sandals. Go."
5. **No teaching dump** — emergency mode keeps the why to one line; full reasoning on request later.

## Hard rules
- Never block on missing info — pick the safest owned default and say what it assumed.
- Never suggest buying in emergency mode (no time, defeats the purpose).
- If wardrobe truly can't produce a clean occasion-fit outfit, say so honestly and give the closest.

## Output
One decided owned outfit, spoken fast, one optional swap, ready in < 3 s.
