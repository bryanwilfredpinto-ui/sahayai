# QUALITY — Chitti Government Quality Operating contract

> Quality is its own pillar. This wraps the [EVALS](EVALS.md) gates with the platform
> quality stack ([QUALITY_STATUS.md](../QUALITY_STATUS.md), [SAHAYAI_MASTER §6](../SAHAYAI_MASTER.md)).

## The five quality layers (CGQOS)
| Layer | Bar | Where |
|---|---|---|
| **Scheme integrity** | 99% real+sourced, 0 fabricated | [evals/scheme_accuracy.md](evals/scheme_accuracy.md), Trust Agent veto |
| **Eligibility correctness** | 95% verdict accuracy; 0% guess-to-eligible | [evals/eligibility_accuracy.md](evals/eligibility_accuracy.md) |
| **Fraud safety** | ≥95% recall, low false-positive | [evals/fraud_detection.md](evals/fraud_detection.md) |
| **Accessibility** | 100% (4 users + 8 profiles); blind/illiterate ≥95% | [evals/accessibility_eval.md](evals/accessibility_eval.md) |
| **Hallucination/Privacy** | <1% / 100% on-device | [evals/hallucination_eval.md](evals/hallucination_eval.md), [guardrails/privacy.md](guardrails/privacy.md) |

## Platform stack (inherited)
- **Observability** — `lib/observability.py` per-request audit + `x-chitti-response-time-ms`.
- **Quadrails** — `lib/quadrails.py` rails gate prompts; Compliance INJECT adds the
  government disclaimer.
- **wrap_llm** — `government_deepseek.py` wrapped; deterministic fallback when DeepSeek down.
- **Swarm** — daily/weekly/monthly cycle; **HIGH-risk → Sire approves** every skill change.
- **Per-response widget** — 🔊/🤖/👍/👎 on every box → Founder daily digest.

## Merge-blockers (a failure here is a defect, not a feature gap)
- Any fabricated scheme · any approval guarantee · any guessed-to-eligible verdict.
- A response box without the per-response widget.
- The language dropdown not translating the page.
- A colour-only verdict · an audio-only or visual-only flow.
- A side-effecting action not behind `chittiConfirmAndDo()`.

## Honest measurement
Numbers reported only after the harness runs. LLM-phrasing metrics gated on funding +
Vaani relevance-rail are `AUTOMATION-LIMITED`, never fabricated.
