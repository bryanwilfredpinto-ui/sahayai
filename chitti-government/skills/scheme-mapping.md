# SKILL 1 — Scheme Mapping

Map a citizen profile + life stage → the set of **real, sourced, relevant** central +
state schemes. Owns the catalog schema (name · ministry · benefit · eligibility ·
documents · official URL · central/state · status · last_verified). Ranks by relevance
and urgency. Never surfaces a scheme without a source ([guardrails/no_fake_schemes.md](../guardrails/no_fake_schemes.md)).
Backed by [Scheme Agent](../swarm/scheme-agent.md) + [backend/data/schemes_seed.json](../backend/data/schemes_seed.json).
