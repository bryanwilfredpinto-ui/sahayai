# GUARDRAILS — Chitti Government

Fields that are never generated by the LLM. Each comes from a structured row served by the backend; DeepSeek phrases them but cannot invent them.

## Never hallucinated

| Field | Source of truth |
| --- | --- |
| Scheme name (EN + HI) | `schemes.name`, `schemes.name_hi` — seeded from [`../backend/data/schemes_seed.json`](../backend/data/schemes_seed.json), curated row. |
| Scheme code / slug | `schemes.slug` — the catalog primary key; uniqueness enforced. |
| Eligibility text (the per-rule pass/fail) | `services/government_eligibility.py::evaluate()` — pure-python rule engine over the scheme's predicate JSON. Deterministic. |
| Application URL | `schemes.source_url` — the official portal link, stored verbatim. |
| Helpline number | `schemes.helpline` — stored verbatim from the curated seed. |
| Status URL | `schemes.status_check_url` — present only when a public status page actually exists. Otherwise the handoff line tells the user "Chitti cannot check this." |
| PIB announcement headlines | Quoted **verbatim** from the PIB RSS XML (`services/government_pib.py`). Deduped by GUID. We do not rewrite headlines. |

## What this means for the eligibility coach

The DeepSeek system prompt at [`../PROMPTS.md`](../PROMPTS.md) is explicit: *"Never invent rupee amounts, helpline numbers, or eligibility rules that are not in the structured input I give you."* Every rupee figure, every exclusion, every required document in the spoken summary must be traceable to a row in `schemes` or to a predicate in the rule-engine output.

## Disclaimer guardrail

`_enforce_disclaimer()` appends the dual-language banner on every reply, including the deterministic fallback path. Tested in both `source = "deepseek"` and `source = "rule_engine_fallback"` envelopes. See [`../PROMPTS.md`](../PROMPTS.md) section 3.

## Status handoff guardrail

Voice handoff strings in `routes/government.py` for the status-tracker are static templates, NOT LLM-generated, because the user is about to leave Chitti for a government portal and we cannot risk a hallucination at the handoff moment.
