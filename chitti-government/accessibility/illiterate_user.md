# ACCESSIBILITY — Illiterate citizen

**Contract:** voice + icons. Picture menus. Voice-out for everything. The single
most important persona for Chitti Government — government's biggest exclusion.
([SAHAYAI_MASTER §7](../../SAHAYAI_MASTER.md))

## Journey
1. Tabs/actions carry an **emoji glyph + spoken label** (🌾 farmer, 👧 girl-child,
   👴 senior, 💼 business, 🛡️ fraud-check).
2. The 26-language dropdown options are **read aloud** on focus so a non-reader can pick.
3. Eligibility verdict + documents + next step are **spoken**; text is the backup.
4. Document checklist uses icons per document, each spoken when focused.

## Requirements
- No flow requires reading. Voice-out covers verdict, reason, documents, deadline.
- Plain-English / plain-vernacular phrasing (Class-5 reading level when written).
- "Say HAAN to confirm" voice-confirmation for the Golden-Rule gate.

## Pass bar
Illiterate-user task success ≥ **95%** ([evals/accessibility_eval.md](../evals/accessibility_eval.md)).
