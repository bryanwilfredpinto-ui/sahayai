# ACCESSIBILITY — Mute / Speech-difficulty citizen

**Contract:** tap-first. Every input is a button or dropdown. Voice input is
**optional, never required.** ([SAHAYAI_MASTER §7](../../SAHAYAI_MASTER.md))

## Journey
1. Profile, eligibility, life-event and fraud inputs are all selectable by tap.
2. The Golden-Rule confirm modal exposes **Yes / No buttons** (not voice-only).
3. Fraud Shield accepts **pasted/typed** text, never requiring a spoken description.

## Requirements
- No flow dead-ends behind a microphone.
- Every voice affordance has a visible tap equivalent.
- Form-helper completes from the saved Twin + tap edits, no speech needed.

## Pass bar
100% of features completable with zero voice input.
