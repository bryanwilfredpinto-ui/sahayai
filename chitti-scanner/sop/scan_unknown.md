# sop/scan_unknown.md — Level 5 (the honesty SOP)

**Trigger:** confidence < 0.55, or conflicting strong signals, or a category with no built
specialist.

**Low confidence**
1. Set category = `unknown`. **Do not guess.**
2. Speak: "I'm not fully sure what this is. Can you describe it, or pick a category?"
3. Show the **picture menu** (icon tiles) for illiterate/mute users.
4. Re-route on the user's pick.

**Conflicting strong signals**
1. Present the **top 2** categories as one-tap choices. The user decides.

**COMING-SOON category** (crop / education / appliance / career / guardian)
1. Show the honest COMING-SOON card: name the specialist + give a real fallback
   (read the label text in-page, or hand off to Vaani).
2. Never fabricate a specialist answer.

**Golden rule of this SOP:** an honest "I don't know" or "that's coming soon" is a **good**
answer. A confident wrong route is a defect.
