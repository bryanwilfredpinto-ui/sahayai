# accessibility/mute_user.md — Level 9

> Mute = **tap / camera-first.** Voice input is optional, **never required.**

## Requirements

- **Whole flow by tap + camera** — capture, category-pick, "open <Chitti>", correction, all
  tappable.
- **Confirm modal is mute-safe** — Yes / No **buttons** in addition to voice (Golden Rule
  gate is tap-first for this profile).
- **Category pick by tap** — when detection is `unknown`, the picture-menu is tappable; the
  user never has to speak to disambiguate.
- **Mic is an affordance, not a gate** — present but never the only path.
