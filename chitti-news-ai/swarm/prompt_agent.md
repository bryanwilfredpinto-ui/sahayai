# Agent 5 — Prompt Agent

> Per COSDF L6 (lines 302-306). Curated copy-paste-ready prompts per profession.
> Rules-only library lookup.

---

## Purpose

Return prompts the user can paste into ChatGPT / Claude / Gemini *today*. Curated, tested, profession-tagged. Never auto-generated by an LLM at runtime.

---

## Input

```json
{
  "role_normalised": "doctor",
  "primary_domain": "healthcare",
  "lang": "en",
  "specialty_hint": "general-practice"
}
```

`specialty_hint` is optional (e.g. `cardiology`, `pediatrics`). If absent, general-practice prompts are returned.

## Rules

1. **Copy-paste ready** — prompt text MUST be self-contained; no `[fill in here]` placeholders without a `prompt_template` flag.
2. **Best-model tagged** — every prompt was tested and tagged with the model it performs best on; cross-model behavior listed in `also_works_on`.
3. **Curator or community-promoted** — prompts enter via two paths:
   - Curated by Sire / domain expert → `tested_by: curator`.
   - Community-submitted (COSDF L20 Phase 2) → reviewed by Trust Agent + ≥ 5 same-profession 👍 votes → promoted to `tested_by: community`.
4. **Warnings on high-risk prompts** — clinical, legal, financial prompts include a 1-sentence warning.
5. **No PII in prompts** — the curated text never contains real patient names, real case numbers, real financial accounts.

---

## Library source

- `data/prompts_library.json` — hand-curated; ~50 prompts per hardcoded hub at v1.1.
- Schema includes `votes_up`, `votes_down`, `tested_at`, `tested_by`.
- Community submissions queued; promoted by Trust Agent.

---

## Ranking

For a given role × specialty, ranking is:
1. `(votes_up - votes_down)` desc
2. `tested_at` desc (newer is better)
3. `category` alphabetical

The frontend renders the top 5 by default; "show more" expands.

---

## Copy interaction

In `chitti_news_ai.html`, each prompt card has a 📋 button that calls `navigator.clipboard.writeText(prompt_text)`. The substrate confirms with:
- Voice (if Voice-First Mode): *"Prompt copied. Paste it into ChatGPT."*
- Toast: *"Copied — paste into your AI chat"*
- ISL panel update (deaf users).

---

## Failure mode

| Failure | Behavior |
|---|---|
| Zero prompts for role | Fallback to `primary_domain` library; if still zero, honest_note: *"No curated prompts yet for 'X'. Be the first — submit one."* (links to Community Intelligence submission form, Phase 2). |
| Clipboard API blocked (iframe / older browser) | Fall back to selection + manual copy hint. |
| User language ≠ prompt language | We do NOT auto-translate prompts (translation changes prompt behavior). Instead, surface in original language + voice-read the explanation in user's language. |

## Test

`backend/tests/test_feed_endpoints.py::test_prompt_agent_curated_only` asserts:
- Every prompt has `tested_at` and `best_model` fields.
- High-risk categories (clinical, legal, financial) have a non-empty `warning`.
- No prompt text contains the strings "[Patient Name]" or "[Case Number]" or other PII placeholders.
