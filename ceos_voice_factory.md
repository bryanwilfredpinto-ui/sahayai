## SECTION 1: PREAMBLE & VISION

### 1.1 Executive Summary
Chitti Voice Factory is SahayAI's community-powered voice substrate — the engine that makes every Chitti speak fluent Hindi, Bangla, Telugu, Tamil, and 22 more Indian languages without relying on Google, Bhashini, Sarvam AI, or any foreign platform. It starts with DeepSeek text generation + basic browser TTS, and gets better every single day as Indian users donate their voices and every Chitti interaction teaches the system more natural language patterns.

**Core Insight:** Every language has millions of native speakers. Every native speaker who uses Chitti is a potential voice donor and language teacher. The community owns the voice. The community improves the voice. No corporation can buy or replicate that.

**The Long Game:** Chitti Bangla will not sound perfect on Day 1. But after 10,000 Bangla-speaking users donate voice samples and 1 million Bangla interactions teach the system natural patterns — Chitti Bangla will speak Bangla the way Bangla people actually speak it. Not textbook Bangla. Real Bangla.

### 1.2 Vision
*"Give every Indian language its own voice — built by the community, owned by the community, for the community. No Google. No government platform. No foreign dependency. Just Indians teaching Chitti to speak Indian."*

### 1.3 Phase Roadmap
| Phase | What | Timeline |
|---|---|---|
| Phase 1 | DeepSeek text + Web Speech API TTS (basic quality, honest) | NOW |
| Phase 2 | Community voice donations replace TTS per language | 6-12 months per language |

## SECTION 23: SOP (5 PROCEDURES)

| SOP | Name | Steps |
|---|---|---|
| SOP 01 | Voice Output | Chitti response text → check user language from profile → select TTS engine (community if available, Web Speech API if not) → speak → ISL panel alongside → log quality |
| SOP 02 | Voice Donation | User opts in → read 10 passage sentences → on-device quality check → consent confirmation → upload to community corpus → Hall of Fame entry → thank you |
| SOP 03 | Active Learning | User says "Chitti, [language] seekh" → Chitti enters learning mode → conversation in that language → extract patterns on-device → quality gate (confidence score) → if 👍 → queue for Swarm → 100 confirmations → promote |
| SOP 04 | Quality Gate | Interaction ends → user rates (👍/👎) → 👍 only → extract language patterns → store as candidate → weekly Swarm validation → 100 confirmations → human review (for life-critical Chittis) → promote to corpus |
| SOP 05 | Chitti Forget | User says "Chitti forget" → all voice donations tombstoned (count preserved, audio deleted) → all learned patterns removed from that user's contribution → Swarm counts adjusted → confirmation to user |

### Skill 10 — 60-Day Language Coach
**Use case:** User wants to learn Kannada in 60 days. Chitti structures a daily learning plan, teaches vocabulary, grammar, and conversational phrases, tracks progress, and certifies completion.

**How it works:**
- User says: "Mujhe 60 din mein Kannada seekhni hai"
- Chitti assesses current level (zero/basic/intermediate)
- Builds 60-day structured plan: 10 mins/day
- Daily lessons: vocabulary + pronunciation + conversation
- Community voice donors provide native pronunciation examples
- Progress tracked in memory — never lost between sessions
- Day 60: completion celebration + "Aap ab Kannada bol sakte hain!"
- Links to formal certification if user wants (Karnataka Govt / ISLRTC)

**Supported languages for coaching:** All 26 — with priority on Hindi, Bangla, Tamil, Telugu, Kannada, Marathi, Gujarati, Odia for Phase 1

**Status:** ⭕ BUILD | Est: 8h
