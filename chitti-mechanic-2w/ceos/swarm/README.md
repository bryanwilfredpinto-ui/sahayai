# SWARM — privacy-safe learning (per [SAHAYAI_MASTER.md §2f](../../../SAHAYAI_MASTER.md))

> Every Chitti Mechanic 2W instance can learn from every other — but only through an
> anonymised, gated, human-reviewed pipeline. The user always owns and can erase their
> contribution.

## What the swarm may learn
- Common real fault patterns (symptom → confirmed cause).
- Fair-cost reality on the ground (what services/parts/tyres actually cost by region).
- Scam patterns (the new tricks workshops/sellers try).
- Which reminders/nudges actually get acted on.

## The gate
1. **Anonymised** — no RC, name, number, location, or any Vault content is ever shared.
   Patterns only, stripped of identifiers.
2. **≥100 confirmations** — a pattern is never promoted from a single instance.
3. **High-risk human review** — anything touching safety, diagnostics, or money is
   reviewed by Sire before it lands in `skills/*.md`. Proposals sit in `SWARM_PROPOSED.md`.
4. **Locked decisions are never learnable** — DeepSeek-only, Vaani-sole-interface,
   Golden Rule, no-auto-dial, local-only Vault, honest-stubs.

## "Chitti forget"
Removes the user's data from the device **and** removes their (already anonymised)
contribution from any pending swarm proposal. Forget means forget — everywhere.

## Cadence
Daily collect · weekly validate · monthly review for promotion · quarterly audit.
