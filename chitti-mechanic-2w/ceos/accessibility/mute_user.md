# Accessibility — Mute user

**Tap-only. Voice input is never required.**

- Every one of the 15 features is reachable and completable **by tap alone** — choose
  symptom from a picture/symbol list, pick documents from icons, tap to confirm a reminder.
- **Confirmation is tap-based**: the Golden-Rule `chittiConfirmAndDo()` accepts an explicit
  tap as the "haan" — Chitti never needs the user to speak to act, and never times out into
  yes.
- **Output is still spoken** (the user can hear) and shown as text — mute affects input,
  not output; the 🔊 widget stays available.
- **Symbol-first entry** for symptoms, parts, and documents so nothing requires typing or
  speaking.
- **Emergency** 108/112 is a single tap to confirm; the family cascade is tap-confirmed.
- The 5-element per-response widget's 👍/👎 and feedback can be given by tap (type optional).
- 26-language dropdown is tap-reachable.
- Test: mute journey — complete all 15 features and every confirmation/emergency action
  using taps only, no microphone.
