# Accessibility — Blind user

**Voice-first. The screen is optional.**

- Every result is announced via `aria-live="polite"` AND read aloud (`🔊` of the 5-element
  per-response widget), in the selected language. The first result auto-reads.
- The **15 features work voice-only**: speak the symptom → diagnosis + triage read aloud;
  ask "is my insurance due?" → the date and a fair premium band spoken; "is this bill
  fair?" → the scam verdict spoken.
- Every **rupee figure is spoken digit-grouped** ("eight thousand five hundred"), every
  **date** read in full, every **triage level** as a word: "green — you can do this",
  "red — please see a mechanic".
- No visual-only content, no colour-only status — the 🟢/🟡/🔴 triage is always a spoken
  word too.
- **Emergency** 108/112 is announced and a single large tap; Chitti reads it, never dials.
- Full keyboard + screen-reader: skip-link, single `<h1>`, landmarks, `role=tab`, managed
  focus, visible focus ring. Disability Profile setup is voice-guided.
- 26-language dropdown is reachable + announced; speech follows the chosen language.
- Test: axe-core 0 critical + blind journey (announce + auto-read + every number spoken)
  across all 15 features.
