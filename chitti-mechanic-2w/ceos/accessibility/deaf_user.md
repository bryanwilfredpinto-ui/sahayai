# Accessibility — Deaf user

**Everything spoken is also shown — ISL, symbols, and clear text.**

- Every result that's read aloud is **also fully visible as text** + an icon; no
  audio-only information anywhere across the 15 features.
- **ISL plugin** (per SAHAYAI_MASTER §7) attaches to every `[data-chitti-response]` box —
  the deaf user can play the sign-language rendering of any answer.
- **Symbols carry meaning**: 🟢/🟡/🔴 triage, 🔧 service, 🛞 tyre, 🔋 battery, 🛡️ insurance,
  ⚠️ scam — paired with words, never colour-only.
- **Haptic feedback** confirms taps and fires on urgent reminders (PUC/insurance overdue)
  and on a scam flag — so an alert lands without sound.
- **Emergency** 108/112 is shown as a large visible tap with text + icon; no reliance on a
  spoken prompt.
- 26-language dropdown drives the on-screen text + ISL; captions for any spoken content.
- The 5-element per-response widget's 👍/👎/feedback works by tap; voice is never required.
- Test: deaf journey — complete all 15 features with audio off; ISL panel present on every
  response; every alert visible + haptic.
