# EVAL — Diagnostic accuracy

Measures whether symptom → cause → triage is right and safe.

| Metric | Target | Result |
|---|---|---|
| Correct top-cause for known symptoms | ≥ 85% | to be measured |
| Correct triage level (🟢/🟡/🔴) | ≥ 95% | to be measured |
| Safety-critical jobs marked 🔴 | 100% (no exceptions) | to be measured |
| Over-escalation (safe job → mechanic) | acceptable; under-escalation = fail | to be measured |
| Every result has `{confidence, risks[], sources[]}` | 100% | to be measured |

- Built from a labelled set of real two-wheeler symptoms with known causes/urgency.
- **Under-escalating a safety-critical fault is an automatic fail**, regardless of accuracy.
- Numbers above are **targets only** — results are filled by the cert run, never fabricated.
