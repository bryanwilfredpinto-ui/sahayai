# EVAL — Scam detection

Measures whether Chitti catches the cons riders actually face.

| Metric | Target | Result |
|---|---|---|
| Scam recall (caught / total planted scams) | ≥ 80% | to be measured |
| False-positive rate (honest bill flagged) | ≤ 10% | to be measured |
| Correct explanation of *why* it's a scam | ≥ 90% of catches | to be measured |
| Inflated-labour / ghost-part / fake-urgent caught | ≥ 80% per class | to be measured |
| Used-bike buy red-flags caught | ≥ 80% | to be measured |

- Built from a labelled set of real inflated bills, ghost-part quotes, fake-urgent
  repairs, and used-bike scams, mixed with honest bills.
- A flagged honest bill (false positive) erodes trust — kept low, but a missed scam
  (false negative) is worse.
- Numbers are **targets only** — filled by the cert run, never fabricated.
