## 3. Non-negotiable rules — every session

- **Language auto-detect.** Hindi, Telugu, Tamil, Kannada, Malayalam, Marathi, Bengali, Gujarati, Punjabi, Odia. NEVER force Hindi on non-Hindi users.
- **Permission first.** ALWAYS asks before accessing any document or taking any action.
- **Data on user's phone.** All documents stored on USER'S PHONE ONLY — never on Chitti servers without explicit per-use permission.
- **Personalised examples.** Capabilities articulated using examples from THAT user's life — not generic.
- **Scheme auto-notification.** Any new govt scheme → all eligible masters notified by default.
- **Feedback pipeline.** Master feedback flows directly to SAHAY AI product team. Nothing lost.
- **Free forever.** Free tier is ALWAYS fully functional. Support tiers unlock additional capability — never restrict existing features.
- **No ads. Ever.**
- **Postman Principle.** Chitti never reads, stores, or analyses private data passed between users. Like a sealed letter — Chitti is the postman only. Never the reader.

#### 5.6a AI Daily Tip — from Chitti News AI (LOCKED 2026-05-15)

The morning brief includes **one AI tip per day** — profession-aware, in the master's language. **Not a separate notification.** It rides the existing 07:00 IST brief Chitti PA already speaks. Source product: [Chitti News AI](CHITTI_NEWS_AI_MASTER_SPEC.md).

> *"Aaj ka AI tip for [profession]: [one actionable line in their language]"*

**Pipeline:**

1. **06:45 IST** — `chitti-news-ai` generates the tip (15 min before the brief).
2. **07:00 IST** — Chitti PA morning brief pulls it via internal API call:
   `GET /api/daily-tip?profession=<master_profession>&lang=<master_lang>` on `chitti-news-ai-api`.
3. **Spoken** as part of the existing brief — never a second message, never a second push.
4. **Follow-up** — master says *"AI tip ke baare mein aur batao"* → Chitti PA routes to Chitti News AI for the deeper explanation.

**Ownership:**

| Concern | Owner |
|---|---|
| Tip generation | `chitti-news-ai` |
| Delivery (07:00 IST cron, voice, language, follow-up route) | `chitti-vaani` (Chitti PA) |
| Connecting endpoint | `GET /api/daily-tip` |

**Hard rules:** profession is DeepSeek-extracted (never a fixed list — matches the *Profession → Tools* contract); source article trust score ≥ 70 or honest 503; voice-first delivery via Voice Factory cascade; **no separate notification — one ritual, the morning brief.** Full endpoint contract: [`CHITTI_NEWS_AI_MASTER_SPEC.md §10a`](CHITTI_NEWS_AI_MASTER_SPEC.md#10a-ai-daily-tip--part-of-chitti-pa-morning-brief-locked-2026-05-15).

## 12. Data & privacy — DPDP Act 2023

**Postman Principle is absolute.** No exceptions.

| Data | Stored? | How long | Master control |
|---|---|---|---|
| Name, language | ✅ explicit consent | Until revoked | "Chitti forget naam" |
| Calendar | ✅ explicit consent | Event + 7 days | "Chitti forget appointment" |
| Medicines | ✅ sensitive consent | Until revoked | "Chitti forget medicine" |
| Documents | ✅ per-doc consent | Until revoked | "Chitti forget CV" |
| **Call CONTENT** | ❌ NEVER | Auto-deleted immediately | Never stored |
| **Private messages between users** | ❌ NEVER | Auto-deleted after delivery | Never stored |
| Health data | ✅ optional explicit | Until revoked | "Chitti forget health data" |

## 17. Trial launch checklist — every launch

1 month trial, 10–15 users max. Scale only after all 6 pass. **Sire is always User #1.**

- ✅ Does it work?
- ✅ Does it delight? (NPS > 8)
- ✅ Does it break? (edge cases fixed)
- ✅ Does it cost what we predicted? (API ≤ ₹50K/mo)
- ✅ Postman Principle intact?
- ✅ Does Chitti sound right? (warm, Hinglish, human)

### Ultimate launch test — every feature
Protect the Master? Save the Master? Anticipate? Would a loyal dost do this? Postman? Free? Would I want this for my own mother?
