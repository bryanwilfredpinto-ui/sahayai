# SOP — Roadside Breakdown ("bike won't start / stopped")

**Trigger:** *"meri bike band ho gayi"* / *"start nahi ho rahi"* / one-tap breakdown button.

## Step 0 — Safety + location first
1. *"Aap safe ho? Bike road se side mein hai?"* — get them off the carriageway first.
2. If the rider is **hurt or stranded in an unsafe spot** → jump straight to the
   [family-cascade SOS](../guardrails/emergency-protocol.md) (confirm → alarm → family
   → Chitti relay). **Never auto-dial cops.**

## Step 1 — Won't-start decision tree (free checks first)
| Ask | If… | Then |
|---|---|---|
| Self-start cranks? | **No crank, lights dead** | battery / terminal — try cleaning terminal, kick-start if available |
| | **No crank, lights fine** | side-stand sensor / kill-switch (Activa/Splendor BS-VI) / starter |
| | **Cranks, won't fire** | fuel + spark |
| Petrol hai? Reserve? | empty / reserve not switched | the #1 cause — fixed free |
| Kill switch + side stand? | engaged | flip kill-switch to RUN, stand up — free fix |
| Choke (carb bikes, cold)? | not used | apply choke, retry |
| Spark plug wet/fouled? | yes | dry/clean plug if rider is able (🟡 DIY-assisted) |

## Step 2 — Verdict
- **Fixed roadside (free/cheap)** → log it, offer prevention tip.
- **Can't fix, bike is safe to push** → nearest mechanic (geo) + brand
  [RSA number](../guardrails/emergency-protocol.md) (dial needs Golden-Rule confirm).
- **Unsafe (🔴 Safety red line)** → DO NOT RIDE → tow/push → cascade if stranded.

## Hard rules
- Free checks (fuel, reserve, kill-switch, side-stand) **before** any "go to mechanic."
- RSA numbers are info; **dialling requires a tap or haan** ([§2g](../../SAHAYAI_MASTER.md)).
- Never auto-dial 100 / 108 / 112 — family cascade only.

## Accessibility
Spoken step-by-step + picture decision tree + tap answers (mute/illiterate). Safety
verdict spoken first (blind) and shown as symbol+word+flash (deaf). "Say HAAN or tap
to call family."
