# SOP — Used-Bike Inspection (100-point inspector)

**Trigger:** *"yeh second-hand bike le lun? check kar do"* — buying a used 2-wheeler.

## Steps
1. **Bike + ask price** — model, year, odo, asking price. Pull the fair resale band.
2. **Walk the rider through the checklist** (spoken + picture, one zone at a time):
   | Zone | Check |
   |---|---|
   | 🔴 **Safety-critical first** | brakes bite firm? tyres (cord/cut/age)? steering free play? fork leak? chain kink? |
   | Engine | cold-start (hides smoke); idle steady? blue/white smoke? knock? |
   | Electrical | self-start crisp? lights/horn/indicators? battery age? |
   | Frame/body | accident weld marks? bent forks? rust under tank? |
   | Drive | chain slack + rust; sprocket teeth hooked? |
   | Documents | RC, insurance, PUC valid? challan pending? chassis = RC? |
3. **Each zone → spoken verdict + symbol** (✅/⚠️/🔴) — never colour-only.
4. **Score + cost-to-fix** — sum to a buy/skip read: *"engine + brakes theek, par chain
   set jald badalna padega (~₹3 000). Asking ₹45 000 — ₹42 000 tak baat karo."*
5. **A 🔴 safety item = walk away or fix-before-ride** — never "looks fine, buy it" on
   a brake/tyre/steering red line.

## Hard rules
- Safety zones inspected **first** and weighted highest ([../guardrails/safety-rules.md](../guardrails/safety-rules.md)).
- Bands, not a single "right" price; confidence band on the overall read.
- If a [Vehicle Health Passport](../memory/vehicle_health_passport.md) exists, surface
  the Trust Score — a verified history beats a visual inspection.
- Never accuse the seller of fraud — *"yeh weld accident ka ho sakta hai, confirm karo."*

## Accessibility
Picture checklist + spoken walk-through; tap ✅/⚠️/🔴 per zone (mute); each verdict
spoken (blind) + symbol+word+ISL (deaf); works zone-by-zone on 2G.
