# ACCESSIBILITY — Cognitive User (Persona: Meena, ~2 crore Indians)

> Learning disability, low numeracy, early dementia, or simply cognitive overload under stress. For
> her, a screen full of indicators and a ticking timer is a recipe for a **panic decision** — exactly
> what scam tip-sheets engineer. The fix is **one idea per screen, plain words, and no rush.**
> Implements [CONSTITUTION.md](CONSTITUTION.md) Art. 2, 8 and [ACCESSIBILITY.md](../ACCESSIBILITY.md).

## What she needs
- **One idea per screen** — not 39 indicators dumped at once.
- **Plain words**, short sentences, the same word for the same thing every time (consistent vocabulary).
- **No urgency, no countdowns** — time pressure breaks cognitive users worst of all.
- Honest framing that doesn't overload: "here is the one main thing; ask me for more if you want."

## How Chitti Technicals serves her
| Need | Implementation |
|---|---|
| One idea per screen | Lead with the **single** 5-state verdict + one sentence; details (RSI/MACD/stop) revealed on request, not all at once [STEAL: Incite "talk, don't tabulate"] |
| Plain language | DeepSeek phrases at a low literacy level; consistent terms; RSI/MACD stay English but always re-explained simply |

| Calm tone on loss | Loss-spiral cool-down (Art. 6) speaks calmly; crisis keywords → Tele-MANAS 14416 (no LLM) |
| Repeat freely | 🔊 repeat on every box; she can re-hear without penalty |

## Failure modes to prevent
- A wall of indicators / numbers shown at once → overload → panic → defect (one idea per screen).
- **Any countdown / urgency** → engineered panic → defect (Art. 8 — it mirrors the scam).
- Inconsistent vocabulary ("Sell" here, "bearish" there, "downtrend" elsewhere for the same thing) → confusion → defect.
- Jargon dumped without a plain re-explanation → defect.
- A confident "Strong Buy" that pressures a fast decision → predatory for this user → defect (Art. 4, 8).

## Test procedure (part of [../EVALS.md](../EVALS.md) + BO5 gate)
**Tester role-plays low numeracy + easily overwhelmed.** Any language:
1. Read a stock → confirm the **first** screen shows **one** verdict + one sentence, not a table.
2. Confirm **no timer / urgency** anywhere; Chitti's tone is unhurried.
3. Ask "why?" → exactly one more fact appears, in plain words; ask again → one more.
4. Check vocabulary consistency across the verdict, RSI, and disclaimer.
5. Trigger a simulated loss-spiral → calm cool-down message, no pressure.
**Pass = the core verdict is understandable in one calm sentence with no overload and no time pressure.**
