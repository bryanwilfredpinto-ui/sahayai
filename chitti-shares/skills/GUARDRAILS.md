# GUARDRAILS

The deterministic layer that runs **before** DeepSeek touches anything. Story Mode and Ask Chitti are generated *from* these numbers, never around them.

## Inputs Chitti Shares is allowed to compute on

| Class | Fields | Source |
|---|---|---|
| **Price** | LTP, % change, day high/low, 52-week high/low | `angel_client.get_quote` |
| **Volume** | day volume, avg-20 volume, volume ratio | `angel_client` candles |
| **OHLC** | full OHLC array per timeframe (1m / 5m / 15m / 1H / 4H / Daily / Weekly / Monthly) | `intraday_candles.py` + `angel_client` |
| **Fundamental ratios** | P/E, P/B, ROE, ROCE, debt-to-equity, current ratio, dividend yield, PEG, market cap | [`screener_client.fundamentals`](../backend/services/screener_client.py) |
| **Financial statements** | Quarterly P&L (last 8), annual P&L / BS / CF | `screener_client.financials` |
| **CAGR** | 3y / 5y / 10y Sales, Operating Profit, Net Profit | [`fundamentals_extras.cagr`](../backend/services/fundamentals_extras.py) |
| **Shareholding %** | Promoter / FII / DII / Public / Govt — quarterly | `screener_client.shareholding` |
| **Dividend history** | per-year dividend record (when screener exposes it) | `screener_client` |
| **News** | per-stock + market RSS headlines | `news_client.fetch_*` |

## How Story Mode is constrained

Story Mode (60-second narrative, [`../TODO.md`](../TODO.md) §A and §J) is generated by passing the **already-computed** ratios + CAGR + last-quarter results + headline news to DeepSeek with a `"narrate, don't predict"` instruction. The narrative is locked to the numbers — there is no path where Story Mode invents a P/E or a price target.

## Roshan Indicator hard rule

The Roshan rule reads `iloc[-2]` (last *closed* candle), never `iloc[-1]` (in-progress). This is enforced in [`services/scanner.py`](../backend/services/scanner.py) and reiterated in the technical agent system prompt in [`../PROMPTS.md`](../PROMPTS.md) §6. Breaking this rule produces look-ahead bias.

## Compute-only differentiators

5D Snowflake, Confidence Dial, Risk-Fit Dial, Performance vs NIFTY, Returns calculator — all live in [`services/snowflake.py`](../backend/services/snowflake.py) and [`services/returns.py`](../backend/services/returns.py) and never round-trip the LLM. They stay alive when DeepSeek is rate-limited or the hard cap (₹100/day) is breached.

## Quota cap is a hard gate

`@tracked` in [`usage_tracker.py`](../backend/services/usage_tracker.py) pre-checks the IST-day spend; over the hard cap returns HTTP 503 `BUDGET_CAP_EXCEEDED`. The page degrades to compute-only mode rather than serving stale or invented numbers.
