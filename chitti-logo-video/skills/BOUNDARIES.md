# BOUNDARIES — Chitti Logo + Video

Hard "never" rules. Violating any of these breaks the contract with Bryan and the user.

## 1. Never claim AI-photorealistic video today

The video endpoint returns a hand-built 640x360 SVG card. It is **not** an MP4, not generated by Pika / Runway / Sora, not "AI-generated" in any sense the user would recognise. Marketing copy must reflect this. See [`./PERSONALITY.md`](./PERSONALITY.md) "What I never say".

## 2. Never silently swap mock for real

The moment a real provider lands, every response must update its `supplier` field from `"mock"` to the actual supplier name (`"replicate"`, `"pika"`, etc.) **and** the disclaimer must change. Bryan signs off on the swap before code ships. See `_replicate_generate()` stub in [`../backend/services/logo_service.py`](../backend/services/logo_service.py) and the `VIDEO_PROVIDER` branch in [`../backend/services/video_service.py`](../backend/services/video_service.py).

## 3. Never charge for the stub

No paywall, no sign-up, no email capture, no "upgrade to download". Free until the real generators ship — and even then, the stub remains the free-tier fallback (see [`./VALUES.md`](./VALUES.md) point 5).

## 4. Never store brand name without consent

No DB exists today (see [`../DATABASE.md`](../DATABASE.md)). When asset storage lands (P1 in [`../TODO.md`](../TODO.md)), brand names persist only if the user explicitly opts in. No silent telemetry of brand names. No fine-print "by clicking generate you agree…".

## 5. Never embed a real video URL pretending to be the user's generation

The mock URL is a `data:image/svg+xml` literal. It is **never** swapped for a YouTube link, a stock-footage URL, or someone else's generation. The user sees their own job id printed on the placeholder card. See `_placeholder_url()` in [`../backend/services/video_service.py`](../backend/services/video_service.py).

## 6. Never block on accessibility before AI

This is Sahay AI rule #2 (see [`../CONTEXT.md`](../CONTEXT.md) Accessibility section). Even in stub mode, every SVG carries `aria-label`, every button has a text label, every touch target is >= 48x48 dp.

## 7. Never call an LLM in v1

Today's stub uses zero LLM calls. Adding one without scope sign-off violates the "honest stub" pattern — see [`../PROMPTS.md`](../PROMPTS.md).

## 8. Never break Chitti Voice Factory's neutrality

If we route narrator TTS through Voice Factory (P0 item 11 in [`../TODO.md`](../TODO.md)), we use its public API like any other client. No private hooks, no Tier-C silent fallback.
