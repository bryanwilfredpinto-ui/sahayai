# SWARM — level-based financial hierarchy (one Chitti, internally evolving)

> Not separate products. **Internally Chitti evolves** through levels and consults
> specialist agents. The final flow: user query → relevant agents vote → Trust Agent
> validates → confidence score → final answer (with risks + sources + reasoning).

## Level agents (escalating expertise)

| Level | Agent | Owns |
|---|---|---|
| 1 | **Bookkeeper** | record/classify transactions, cash & udhaar book |
| 2 | **Accountant** | registers, journal, basic reconciliation |
| 3 | **Senior Accountant** | full reconciliation, depreciation, period close |
| 4 | **GST Agent** | registration, ITC, GSTR reconciliation, GST health |
| 5 | **Income-Tax Agent** | slabs, regime, capital gains, advance tax, ITR guidance |
| 6 | **Audit Agent** | controls, anomalies, variances, audit readiness |
| 7 | **Compliance Agent** | ROC/MCA/TDS/PF/ESI calendar + penalty prediction |
| 8 | **Business Consultant Agent** | Business Doctor, growth, cost reduction |
| 9 | **CFO Agent** | forecasting, budgeting, cash-flow, CFO dashboard |
| 10 | **CA Partner Agent** | final review, HIGH-risk judgement, "see a human CA" call |

## Specialist agents (cross-cutting)

- **Government Benefits Agent** — scheme/subsidy eligibility + ₹ impact (the moat).
- **Fraud Agent** — fake GST, duplicates, overbilling, vendor risk.
- **Accessibility Agent** — guarantees voice/ISL/symbol/picture/lang on every answer.
- **Trust Agent** — validates every figure's provenance, attaches confidence + risks,
  blocks any guarantee, forces "see a CA" on HIGH-risk. The last gate before output.
- **Memory Agent** — reads/writes the Financial Twin, builds the timelines.

## Voting + validation

Relevant agents each return `{verdict, confidence, why, sources}`. The Trust Agent
rejects any answer that (a) contains a guarantee, (b) shows a rupee figure without
engine provenance, (c) hides a risk, or (d) is HIGH-risk without a professional-review
recommendation. Disagreement → lower confidence + "recommend professional review".
