# Accessibility — Illiterate user

**Voice + icons. No required reading.**

- Icon-first tabs and chips (📊 💰 🧾 🛡️ 🏛️ 🧬) with a 🔊 voice label on every control
  and every result.
- Picture menus; the first result auto-reads aloud.
- All copy in the user's language (26-lang dropdown, native script) AND spoken.
- Numbers spoken in words; "money you are owed" and "money you can save" stated plainly.
- Test: illiterate voice/tap journey — reach an answer and hear it, typing nothing.
