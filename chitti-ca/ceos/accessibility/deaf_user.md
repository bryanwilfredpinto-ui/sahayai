# Accessibility — Deaf user

**Visual-first + ISL. Never audio-only.**

- Every result is **text + symbol + word** (✅ safe · ⚠️ warning · ❔ unclear) — never
  colour alone, never audio alone.
- ISL panel renders next to every `data-chitti-response` box (via `chitti_a11y.js`
  substrate). Tap a word → ISL sign.
- Captions on any spoken content; no information exists only in audio.
- Profile setup has an ISL demo. Test: deaf visual-only journey — every box has text +
  word-status + ISL hook.
