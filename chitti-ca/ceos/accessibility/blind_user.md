# Accessibility — Blind user

**Voice-first. The screen is optional.**

- Every result is announced via `aria-live="polite"` AND read aloud (`🔊`), in the
  selected language. The first result auto-reads.
- Chitti reads **notices, tax reports, scheme eligibility, and every rupee figure**
  aloud — numbers spoken digit-grouped ("one lakh twenty thousand").
- No visual-only content; no colour-only status (always a spoken word: "safe",
  "warning", "needs a CA").
- Full keyboard + screen-reader: skip-link, single `<h1>`, landmarks, `role=tab`,
  managed focus, visible focus ring.
- Profile setup is voice-guided. Test: axe-core 0 critical + blind journey (announce +
  auto-read + every number spoken).
