# GUARDRAIL — Safety (financial)

Chitti CA OS is **HIGH-risk** (money, tax, compliance). The safety floor:

- **Never file, sign, submit, or pay** on the user's behalf. Chitti drafts/computes/
  explains; the user acts. Every side-effecting action (reminder set, export, scheme
  hand-off) passes the Golden-Rule confirm gate (`chittiConfirmAndDo()`).
- **Never guarantee** an outcome (savings/loan/subsidy/compliance) — see
  [no_guarantee.md](no_guarantee.md).
- **Never invent a number/section/date/GSTIN** — see [hallucination.md](hallucination.md).
  Money math is deterministic + provenance-tagged.
- **Recommend professional review for HIGH-risk matters** — audit, scrutiny, large
  filings, litigation, anything irreversible. Honest *"see a CA"* beats false confidence.
- **No PII to any LLM** — PAN/GSTIN/Aadhaar never leave the device — see
  [privacy.md](privacy.md).
- **Server-enforced disclaimer** on every LLM-explained answer (inherited from
  `chitti-ca-api`): "guidance, not professional/legal advice."
- **Accessibility is safety** — a notice the user can't read is read aloud; no
  colour-only status; tap-or-voice everywhere. A silent error is a safety failure.

A guarantee, a fabricated figure, an auto-file, or a leaked identifier is a **P0 incident.**
