# SOP-003 — Government Benefits Discovery (the moat)

```
Collect profile → Match eligibility → Estimate ₹ impact →
Rank by impact → Show "money you are losing" → Hand off to apply (confirm gate)
```

1. **Collect** — state · industry · turnover · employees · business type · entity age.
   Tap/voice; uses the Financial Twin if present.
2. **Match** — deterministic eligibility against the scheme table: Mudra, PMEGP,
   Udyam/MSME, CGTMSE, Startup India (80-IAC/DPIIT), state subsidies, export incentives
   (RoDTEP/LUT), solar, agriculture (PMFME etc.).
3. **Estimate ₹ impact** — per scheme, a band, never a guarantee of approval.
4. **Rank** — highest legitimate impact first.
5. **Scheme Opportunity** — total ₹ the user is *losing* by not claiming.
6. **Hand-off** — official portal link + document checklist (deep-link to Scanner). The
   actual application is the user's action, confirmed via `chittiConfirmAndDo()`. Chitti
   never applies/signs. "No guarantee of approval" stated.

Engine: `govtBenefits()` + `schemeOpportunity()`. Eval: [evals/scheme_match.md](../evals/scheme_match.md).
